# Meu Primeiro Portfólio

Projeto desenvolvido para o desafio **Meu Primeiro Portfólio** do Programa Trilhas.

O objetivo do projeto é criar uma página pessoal simples para apresentar meu perfil, meus projetos e meus certificados, utilizando os conhecimentos aprendidos em desenvolvimento Front-end.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Funcionalidades

O portfólio possui:

- Página inicial com foto, nome e descrição
- Página "Sobre mim"
- Página com meus projetos
- Acesso aos meus certificados
- Links para GitHub e LinkedIn
- Layout responsivo
- Animações simples nos botões e elementos da página
